# openstatus_status_page_component (Resource)

Manages a component on an OpenStatus status page. Components can be linked to a monitor or be static entries with manually managed status.

## Example Usage

```terraform
resource "openstatus_status_page_component" "api_monitor" {
  page_id    = openstatus_status_page.main.id
  type       = "monitor"
  monitor_id = openstatus_http_monitor.api.id
  name       = "API"
  order      = 1
}

resource "openstatus_status_page_component" "info" {
  page_id = openstatus_status_page.main.id
  type    = "static"
  name    = "Third-party Services"
  order   = 2
}
```

## Schema

### Required

- `page_id` (String) ID of the status page this component belongs to. Changing this forces a new resource.
- `type` (String) Component type. Valid values: `monitor`, `static`. Changing this forces a new resource.

### Optional

- `monitor_id` (String) ID of the monitor to link. Required when `type` is `monitor`.
- `name` (String) Display name of the component (max 256 characters).
- `description` (String) Description of the component (max 1024 characters).
- `order` (Number) Display order of the component on the status page.
- `group_id` (String) ID of the component group this component belongs to.
- `group_order` (Number) Display order of the component within its group.

### Read-Only

- `id` (String) The ID of the component.
- `created_at` (String) Timestamp when the component was created.
- `updated_at` (String) Timestamp when the component was last updated.
