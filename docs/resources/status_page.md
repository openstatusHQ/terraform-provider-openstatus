# openstatus_status_page (Resource)

Manages an OpenStatus status page. Status pages provide a public or private view of your monitored services.

## Example Usage

```terraform
resource "openstatus_status_page" "main" {
  title        = "Example Status Page"
  slug         = "example-status"
  description  = "Status page for Example Inc."
  homepage_url = "https://example.com"
  contact_url  = "https://example.com/contact"
}
```

## Schema

### Required

- `title` (String) Title of the status page (1–256 characters).
- `slug` (String) URL slug for the status page (1–256 characters).

### Optional

- `description` (String) Description of the status page (max 1024 characters).
- `homepage_url` (String) URL to your homepage.
- `contact_url` (String) URL to your contact page.
- `icon` (String) URL to an icon image for the status page.
- `custom_domain` (String) Custom domain for the status page.
- `access_type` (String) Access control type. Valid values: `public`, `password`, `email-domain`.
- `password` (String, Sensitive) Password for the status page. Required when `access_type` is `password`.
- `auth_email_domains` (List of String) Allowed email domains. Required when `access_type` is `email-domain`.

### Read-Only

- `id` (String) The ID of the status page.
- `published` (Boolean) Whether the status page is published.
- `theme` (String) The theme of the status page.
- `created_at` (String) Timestamp when the status page was created.
- `updated_at` (String) Timestamp when the status page was last updated.
