# OpenStatus Provider

The [OpenStatus](https://www.openstatus.dev/) provider allows you to manage monitors, notifications, and status pages using the OpenStatus API.

## Installation

```terraform
terraform {
  required_providers {
    openstatus = {
      source = "openstatusHQ/openstatus"
    }
  }
}
```

## Example Usage

```terraform
provider "openstatus" {
  # Set via OPENSTATUS_API_TOKEN environment variable or here:
  # api_token = "your-api-token"
}

resource "openstatus_http_monitor" "api" {
  name        = "API Health Check"
  url         = "https://api.example.com/health"
  periodicity = "5m"
  method      = "GET"
  active      = true
  regions     = ["fly-iad", "fly-ams"]
}

resource "openstatus_status_page" "main" {
  title = "Example Status Page"
  slug  = "example-status"
}
```
